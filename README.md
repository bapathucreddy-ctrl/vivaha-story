# The Vivaha Stories

A buildless, responsive photography portfolio inspired by the forest-green, gold and cinematic editorial styling in ref12.mp4.

Open `dist/index.html` or serve `dist/` using a static HTTP server. No package installation or build step is required.

Features: slideshow with pause controls, portfolio filtering, project photo viewer with keyboard and touch navigation, mobile navigation, reveal transitions, reduced-motion support, FAQs and an enquiry composer with email and WhatsApp handoff. Enquiries are not stored on a server.

Photography comes from the locally downloaded Manoj Gangula Behance collection. `prepare-assets.ps1` creates two optimized JPEG sizes from those source images. Company and contact information comes from the extracted public profile. No testimonials, client counts or pricing are invented.
